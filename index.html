Project 01 · Mobile App · Case Study

Fortivy — Mobile App Design

The Problem

Users needed a clear, structured mobile experience with intuitive navigation and a design that builds trust from first use.

The Solution

Designed a clean mobile interface with strong visual hierarchy, simplified user flows, and a scalable component system.

Key Design Decisions
  • Simplified navigation to reduce cognitive load
  • Used strong visual hierarchy for better readability
  • Designed mobile-first for accessibility
  • Built reusable component library in Figma

"Improved usability with a seamless, intuitive experience users can navigate effortlessly."

Project 02 · Web Design · Dashboard

Financial Dashboard — Banking UI

The Problem

Users struggled to interpret complex financial data quickly, leading to poor decision-making and low engagement.

The Solution

Designed a clean dashboard with clear data visualization, logical information grouping, and instant key-metric visibility.

Key Design Decisions
  • Prioritized key metrics in the primary view
  • Used consistent data visualization patterns
  • Reduced visual noise for faster scanning
  • Designed with accessibility in mind

"A dashboard that makes complex financial data feel simple, clear, and instantly actionable."

Project 03 · Web Design · Landing Page

Finance Landing Page — Conversion UI

The Problem

Finance landing pages often overwhelm visitors with too much information, resulting in poor conversion rates and drop-offs.

The Solution

Designed a focused, conversion-optimized page with a clear value proposition, strategic CTAs, and a clean visual layout.

Key Design Decisions
  • Single, clear call-to-action above the fold
  • Trust signals placed near conversion points
  • Clean typographic hierarchy for quick scanning

"A landing page designed to communicate value instantly and convert visitors into users."
